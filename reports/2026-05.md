直近90日のランキングを views / estimatedMinutesWatched / 流入経路の3軸で見たところ、**まったく性質の異なる2系統のコンテンツが共存している**ことが明らかになりました。

  - 平均視聴維持率: 30〜45%

### 系統B: 最近のAI / ChatGPT Shorts 群（2026年制作）

- ジャンル: ChatGPT / Copilot / NotebookLM / Vibeコーディング 等
- 動画長: 40〜120秒（一部Shorts指定でも実は90秒超）
- **直近90日の挙動**:
  - Shortsフィード（SHORTS）流入比率: **90〜93%**（検索/関連動画はほぼゼロ）
  - 平均視聴維持率: 5〜15%（短尺なので一概に低いとは言えないが…）
  - エンゲージメント率: **0.2〜0.6%**

### この二重構造が意味すること

- **登録者1,730人を支えているのは間違いなく系統A（長尺）** — 検索で見つけて、リピート視聴し、コメント・いいねを残しているのはこちらの層

- ただし系統B の方が**最新トピックでリーチが取れる**点は有用なので、捨てるのではなく**チャンネル本体への動線を作る**のが課題

## 4. パターン別の発見（パターンA〜F より抜粋）

### パターン A（維持率の底）
維持率 10% 未満の動画は **すべて 2026年制作の AI 系 Shorts**。共通点:
- 「3分で作る」「60秒で解説」など**結論先取り型のタイトル**
- 冒頭フックでテーマ説明に時間を使い、肝心の "やり方" が後半に集中
- → 冒頭3秒で結論→ハイライト→詳細、という構成テストの余地

### パターン B（流入経路 × 維持率）
- 検索流入が主の動画 = 維持率が高い（テーマと意図が一致）
- Shortsフィード流入が主の動画 = 維持率が低い（受動視聴で離脱しやすい）
- → これは構造的なもので、Shorts全般の特性とも言えるが、**Shortsの中で維持率を上げる勝ち筋**を探る価値はある（パターンAと連動）

### パターン C（コメント密度）
エンゲージ率 1.0% 超え（議論が起きるテーマ）の動画は **10本中8本が 2021年の長尺 Kaggle/データ業界キャリア系**。
- 「データサイエンティスト業務スタイル」(1.62%)

- 「データアナリスト未経験から職種転換」(1.57%)
- 「Kaggleタイタニック パート③」(1.58%)

**→ "キャリア論 + データサイエンス" の組み合わせが議論を生む**。最新版（2026年の AI 時代における「データ職」「機械学習エンジニア」のキャリア論）が刺さる可能性が極めて高い

### パターン D（シリーズ効果）

## 6. 次の機能化候補（プレイブック運用で詰まった箇所）

- **APIで `averageViewPercentage` ランキングが取得できない** — YouTube Analytics API が `dimensions=video` + `metrics=averageViewPercentage` で 500 を返す。views と minutes から自前計算（avg_view_sec / duration_sec）するロジックを `/api/rankings` に組み込むと運用が楽
- **チャンネル全体のデモグラ取得**: 動画別 demographics は匿名化で空になりやすい。チャネル全体（ids=channel==MINE で video フィルタなし）の demographics を取得できる新エンドポイントが欲しい
- **指標間順位の食い違いビュー** — 今回の最大の発見はこれだった。views Top と minutes Top の差分を自動表示する画面を `/rankings` に追加すると毎月の分析が劇的に速くなる
- **コメント密度ランキング** — `/api/videos` のデータから手動算出。`/rankings` の metric 選択肢に "engagement_rate" として追加すると便利
- **登録者推移の継続記録** — `POST /api/collect` を日次 cron で実行する運用を開始。現状では Sheets 履歴が無いためパターン F（登録転換）が動かない
