# 分析プレイブック — エンゲージメント向上のための運用ガイド

本ドキュメントは、本ツール（YouTube Analytics ダッシュボード）を使って自チャンネルの**改善ポイントを見つけ、打ち手を回す**ための運用手順をまとめたものです。

対象は **教育・解説系（ノウハウ／技術／ビジネス）チャンネル、1,000〜10,000登録の成長期**。最重要ゴールは**エンゲージメント向上**としています。

関連ドキュメント:
- システム構成: [`design.md`](./design.md)
- エンドポイント仕様: [`api.md`](./api.md)
- 登録者推移の保存形式: [`sheets.md`](./sheets.md)

---

## 1. はじめに（目的と前提）

### この資料の位置づけ
本ツールは10本のAPIと4ページ（ダッシュボード / ランキング / 動画詳細 / 比較）でデータを可視化しますが、**「どの画面をどう読み、どんな仮説を立て、何を改善するか」** という運用知見は今までドキュメント化されていませんでした。本書がその空白を埋めます。

### 「エンゲージメント」の定義
本書では次の2軸で扱います。教育系チャンネルでは特に**視聴維持の質**がアルゴリズム的にも視聴者体験的にも重要です。

| 軸 | 指標 | 取得元 |
|---|---|---|
| 視聴維持 | `averageViewPercentage`（平均視聴維持率） / `averageViewDuration`（平均視聴時間） | YouTube Analytics API |
| アクション率 | `(like_count + comment_count) / view_count` | YouTube Data API v3 |

### データ取得の制約
- **YouTube Analytics API は直近90日まで** — 長期トレンドは Sheets スナップショット（`/api/channel/timeseries`）で補う
- **動画別の登録者増減は取得不可** — 7. の代替手法で粗推計する
- **CTR（クリック率）と秒単位の維持率カーブは未取得** — YouTube Studio 側で確認する補助フロー

## 2. KPI ツリー

エンゲージメント向上は単一指標ではなく、3系統の指標に分解して観測します。

```
エンゲージメント向上
├─ A. 視聴維持
│   ├─ averageViewPercentage  ← 「動画の何％まで見られたか」
│   └─ averageViewDuration    ← 「平均何秒見られたか」
├─ B. アクション率
│   ├─ likes / views
│   └─ comments / views
└─ C. 再訪・継続
    ├─ 登録者推移（チャネル時系列）
    └─ 流入経路の "BROWSE/SUGGESTED" 比率（おすすめからの再訪を示唆）
```

各指標は「何が動かしているか」とセットで考えると打ち手が出ます。

| 指標 | 主に動かす要因 |
|---|---|
| averageViewPercentage | 動画長、冒頭フック、構成、テーマと内容の一致 |
| averageViewDuration | 動画長、中盤・終盤の濃度 |
| like_count / view_count | 内容の "鋭さ"、CTA、視聴者層との適合 |
| comment_count / view_count | 議論余地、問いかけ、コミュニティ感 |
| 検索流入比率 (`YT_SEARCH`) | タイトルSEO、説明文、テーマ需要 |
| 関連動画流入 (`SUGGESTED_VIDEOS`) | サムネ、他動画との関連性 |

## 3. 月次の標準分析サイクル

月1回、30〜45分で完走することを想定したワークフローです。

### Step 1 — 全体スナップショット（5分）

**画面**: `/`（ダッシュボード）

確認すること:
1. KPIカード3つ（登録者数 / 総再生数 / 動画数）の前月比デルタ
2. 期間セグメントを **28日 / 90日** で切り替えて推移を見る
3. **登録者推移と総再生数推移の乖離**をチェック
   - 再生数↑だが登録↑が鈍い → サムネ/タイトルで釣れているが内容が刺さっていない
   - 再生数停滞でも登録↑ → 既存視聴者の熱量は高い、露出拡大が課題

### Step 2 — リーダー＆ボトム抽出（10分）

**画面**: `/rankings`

以下の手順で「指標間の順位の食い違い」を見つけます。

1. **`views`** で Top5 と Bottom5 を控える（再生数）
2. **`estimatedMinutesWatched`** で Top5 と Bottom5 を控える（総視聴時間 = 再生数 × 平均視聴時間）
3. **`averageViewPercentage`** で Top5 と Bottom5 を控える（維持率）

判定パターン:

| 再生数 | 維持率 | 解釈 | 次のアクション候補 |
|---|---|---|---|
| 高 | 高 | 王道のヒット | 同テーマで深掘り or 続編 |
| 高 | 低 | 釣りタイトル疑い（サムネ/タイトルが過剰） | タイトル文言・サムネ整合性チェック |
| 低 | 高 | 隠れた良コンテンツ／露出不足 | サムネ刷新、関連動画への内部リンク |
| 低 | 低 | テーマ or 切り口がミスマッチ | 撤退判断 or 切り口変更 |

**注意**: `averageViewPercentage` は動画長に強く依存します（短い動画ほど高くなりやすい）。同程度の長さの動画群で比較するのが原則です。

### Step 3 — 個別動画ドリルダウン（15分）

**画面**: `/videos/[id]`

Step 2 で抽出した動画のうち、**「順位が割れた動画」と「Top/Bottom の極端な動画」**を3〜5本選び、それぞれ次の3パネルを読みます。

1. **時系列パネル**（`/api/videos/{id}/timeseries`）
   - 指標を `views` → `averageViewPercentage` の順に切替
   - 公開直後の立ち上がりカーブと、再加速ポイント（外部流入や検索ヒットの兆候）の有無
   - 維持率の経時変化 — 同じ視聴者層なら時間を通じてほぼ一定。大きく揺れる場合は流入経路の変化を疑う

2. **流入経路パネル**（`/api/videos/{id}/traffic`）
   - 主要な `traffic_source_type` 値:

     | 値 | 意味 |
     |---|---|
     | `YT_SEARCH` | YouTube内検索 |
     | `SUGGESTED_VIDEOS` | 関連動画 |
     | `BROWSE` | ホーム・登録チャンネルのおすすめ枠 |
     | `EXT_URL` | 外部リンク |
     | `YT_OTHER_PAGE` | チャンネルページ・再生リストなど |
     | `NOTIFICATION` | 通知 |

   - 教育系は **`YT_SEARCH` 比率の高さ = テーマ需要への合致** の指標
   - `BROWSE` / `SUGGESTED_VIDEOS` 比率が伸びたら **アルゴリズムに認識された**サイン

3. **視聴者属性パネル**（`/api/videos/{id}/demographics`）
   - `age_group` × `gender` × `view_percentage` で構成（`view_percentage` は **構成比** であって維持率ではない）
   - 想定ターゲットと実態の乖離をチェック
     - 例: 「ビジネス初学者向け」と謳いつつ実は 35-44 歳の経験者層が多い → 説明レベル・例示の調整余地

### Step 4 — 仮説と打ち手の言語化（10分）

抽出した発見を**仮説カード**（後述）に落とし込みます。同時実行する打ち手は**最大2つ**に絞ること。それ以上は効果の切り分けが不可能になります。

## 4. 分析パターン集（着眼点のレシピ）

月次サイクルとは別に、特定の問題意識から逆引きで使えるパターン集です。

### パターン A: 維持率の "底" を探す

| 項目 | 内容 |
|---|---|
| 使う画面 | `/rankings`（`metric=averageViewPercentage` 昇順想定。現UIで昇順切替ができない場合は降順で取得して末尾を見る、または `limit=50` で全件取って手動ソート） |
| 観察対象 | 維持率の低い動画群の共通点（動画長、テーマ、サムネのトーン、公開時期） |
| アクション | 動画長の見直し、冒頭30秒のフック改善、サムネ＝内容の整合性チェック |

### パターン B: 流入経路 × 維持率

| 項目 | 内容 |
|---|---|
| 使う画面 | `/videos/[id]/traffic` を Step 2 で抽出した複数動画で順に確認 |
| 観察対象 | **検索流入優位 vs 関連動画優位**で、どちらの維持率が高いか |
| 解釈 | 検索流入の維持率が高い = テーマと検索ニーズが合致／関連動画流入の維持率が低い = サムネで釣られて来た人が離脱している |
| アクション | タイトルSEOの見直し、サムネの誤誘導要素の除去 |

### パターン C: コメント密度ランキング

| 項目 | 内容 |
|---|---|
| 使う画面 | `/api/videos` を直接叩き、`comment_count / view_count` を手動算出（または将来UIに組み込み） |
| 観察対象 | コメント密度が突出して高い動画＝視聴者の議論余地があったテーマ |
| アクション | 同テーマの**続編・深掘り企画**を組む。コメント欄のFAQをそのまま動画化するのも有効 |

### パターン D: シリーズ効果

| 項目 | 内容 |
|---|---|
| 使う画面 | `/compare` で同シリーズの動画を最大8本まで重ね描き |
| 観察対象 | シリーズ各話の `averageViewPercentage` の劣化曲線（後半話数ほど維持率が下がるパターン） |
| アクション | シリーズの構成見直し（後半に独立性を持たせる、各話冒頭で前提を再提示）、サムネの統一感 |

### パターン E: ターゲット乖離

| 項目 | 内容 |
|---|---|
| 使う画面 | `/videos/[id]/demographics` |
| 観察対象 | 想定年齢層と実視聴者層のズレ |
| アクション | 説明難易度・例示・専門用語の利用頻度の調整 |

### パターン F: 登録転換（粗推計）

| 項目 | 内容 |
|---|---|
| 使う画面 | チャネル登録者推移（`/api/channel/timeseries?metric=subscriber_count`）と動画一覧（`/api/videos`）の `published_at` を重ね合わせ |
| 観察対象 | **登録者数の急増日と前後で公開された動画**の組み合わせ |
| アクション | 急増を生んだ動画の構成要素（テーマ、冒頭、CTAの位置）を抽出して次の動画に展開 |
| 注意 | 動画別 `subscribersGained` は API では取得できないため、あくまで時系列の前後関係からの**粗推計**。3〜7日のタイムラグを見込む |

## 5. 取れない指標への代替アプローチ

### CTR（インプレッションクリック率）
- 本ツールでは取得できません。**YouTube Studio の「アナリティクス → コンテンツ → インプレッションのクリック率」** で確認してください
- 補助運用案: 月次分析時にスプレッドシートの別シートへ CTR を手動転記。`/rankings` の維持率と組み合わせて「CTRも高い × 維持率も高い」動画を「成功動画」と定義する

### 秒単位の視聴維持率カーブ
- 本ツールは `averageViewPercentage`（動画全体の平均値）までしか提供しません
- 「どこで離脱したか」は **YouTube Studio の動画別「視聴者維持率」グラフ** を併用
- 粗代用: `averageViewDuration` ÷ `duration_sec`（`/api/videos/{id}` から取得）で全体の維持率を独自計算可能。Studio との突合確認用

### 動画別の登録者増減
- API で取得不可。パターン F の粗推計で代替する
- 将来的に Sheets に「日次登録者数」を蓄積していけば、より厳密な前後差分が出せる（`POST /api/collect` を毎日実行する運用が前提）

## 6. 改善仮説のテンプレート

分析結果を**仮説カード**として記録します。次月、結果検証する材料になります。

```markdown
## 仮説カード [YYYY-MM-DD]

### 観察事実
- 対象動画: [動画タイトル / video_id]
- 指標: averageViewPercentage = 28%（直近10本平均: 42%）
- 流入経路: SUGGESTED_VIDEOS 65% / YT_SEARCH 12%
- 視聴者属性: 18-24 男性 45%（想定ターゲット: 25-34）

### 仮説
関連動画から「初心者向け」と誤認して流入したが、内容が中級者向けで離脱している。

### 打ち手（次の動画で試す）
1. サムネに「実務経験者向け」を明記
2. 冒頭15秒で「対象読者」を明確に宣言

### 検証指標と期限
- 次回類似テーマの動画公開後14日時点で averageViewPercentage を確認
- 目標: 38% 以上

### 結果（記入は1ヶ月後）
- 実測値: ?
- 学び: ?
```

### 月次ログの蓄積運用

月次分析の結果は `reports/YYYY-MM.md` に保存することを推奨します。雛形:

```markdown
# 月次インサイト YYYY-MM

> 分析対象: [チャンネル名（チャンネルID）]
> 集計期間: 直近90日（YYYY-MM-DD 〜 YYYY-MM-DD）
> 分析実行日: YYYY-MM-DD

- 登録者: 前月比 +XXX（+X.X%）  ※初回は累計値のみ

- 数値根拠を表で（例: 系統別の維持率・流入比較）
- 「だから何をすべきか」の方針を1行で

## 2. ランキング所見
- views Top10（維持率・エンゲージ率併記）

## 3. 個別動画ドリルダウン
Step 2 で抽出した3〜5本について:
- [動画A] — 流入経路 / デモグラ / 解釈 / 次の打ち手
```

- **初回月**は「先月の仮説検証」が欠落しても OK。代わりに「最重要発見」が分厚くなる傾向
- **2回目以降**は逆に「先月の仮説検証」が最も重要なセクションになる（PDCAが回り始めるため）
- 「次の機能化候補」は毎月溜まっていくので、定期的に `docs/analysis-playbook.md` の 9章にマージしてバックログ管理する

## 7. やってはいけないこと（アンチパターン）

| アンチパターン | なぜダメか | 代わりに |
|---|---|---|
| 単発の動画の数字だけで結論を出す | n=1 は偶然と区別できない | 直近10本の中央値・平均と比較する |
| 公開直後7日以内のデータで判断 | 関連動画・検索からの流入が伸び切る前 | 14〜30日経過後に再評価 |
| 維持率を絶対値で動画間比較 | 動画長で大きく変わる（短いほど高くなりやすい） | 同程度の長さ（±20%）の動画群で比較 |
| 再生数だけで "成功" を定義 | 教育系は維持率と登録転換が本質 | 「再生数 × 維持率 × 登録転換」の3軸で見る |
| 同時に打ち手を3つ以上試す | 効果の切り分け不可能 | 1動画につき改善ポイントは最大2つに絞る |
| ランキング上位だけ深掘り | 改善余地が大きいのはむしろ Bottom 群 | Top と Bottom の両方を分析対象に |

## 9. 次のステップ（将来の機能化候補）

本プレイブックを実運用しながら、頻繁に行う分析は将来的にツールへ組み込む価値があります。候補:

- **コメント密度ランキング**: 現在UIに無いため、`/rankings` の指標選択肢に追加
- **指標間順位の食い違いビュー**: `views Top` だが `averageViewPercentage Bottom` のような動画を自動抽出して表示
- **登録転換ヒートマップ**: パターン F の粗推計を自動可視化（動画公開日 × 登録者増減）
- **仮説カード CRUD**: ツール内で仮説の登録・検証ステータス管理ができる「Insights」セクションの追加
- **アラート**: 維持率や流入比率が直近平均から大きく外れた動画を自動通知
- **YouTube Studio CSV 取り込み**: CTR や秒単位維持率カーブを月次でアップロード → 動画詳細ページに統合表示

これらは本書の運用を回した上で、実際に「毎月手作業で困っている」と感じた箇所から優先的に検討してください。
