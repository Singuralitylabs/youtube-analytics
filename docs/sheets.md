# Google スプレッドシート構成

## 役割

YouTube Data API は「現在の登録者数」しか返さないため、過去の推移を記録するためだけにスプレッドシートを使用する。
その他のデータはすべて YouTube API から都度取得するため、スプレッドシートへの保存は不要。

---

## スプレッドシート構成

スプレッドシート名: `YouTube Analytics`

シートは1枚のみ使用する。

### シート名: `登録者数履歴`

収集ボタンを押すたびに1行追記される。

| 列 | カラム名 | 型 | 例 |
|----|---------|-----|-----|
| A | 収集日時 | DATETIME | 2026-04-11 14:30:00 |
| B | 登録者数 | INTEGER | 12000 |
| C | 総再生数 | INTEGER | 980000 |

**例（実際のシートのイメージ）**

```
A                    | B      | C
---------------------+--------+---------
収集日時              | 登録者数 | 総再生数
2026-03-01 10:00:00 | 11200  | 910000
2026-03-15 09:30:00 | 11500  | 935000
2026-04-01 11:00:00 | 11800  | 958000
2026-04-11 14:30:00 | 12000  | 980000
```

> 総再生数も合わせて記録しておくことで、チャンネル全体の再生数推移グラフも描画できる。

---

## スプレッドシートIDの確認方法

スプレッドシートのURLから取得する。

```
https://docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit
```

この `{SPREADSHEET_ID}` 部分を `.env` の `SPREADSHEET_ID` に設定する。

---

## アクセス権限

| 方式 | 設定 |
|------|------|
| OAuth 2.0 | YouTube API と同一トークンで認証（スコープに `https://www.googleapis.com/auth/spreadsheets` を追加） |
| スプレッドシートの共有設定 | チームメンバーに閲覧・編集権限を付与することで、アプリ外からも直接確認できる |

## 読み書きの仕様

### 書き込み（POST /api/collect 実行時）

YouTube Data API から現在の登録者数・総再生数を取得し、シートの末尾に1行追記する。

```
操作: spreadsheets.values.append
範囲: 登録者数履歴!A:C
値:   [["2026-04-11 14:30:00", 12000, 980000]]
```

### 読み込み（GET /api/channel/timeseries 呼び出し時）

シートの全行を取得し、日付・登録者数・総再生数の時系列データとして返す。

```
操作: spreadsheets.values.get
範囲: 登録者数履歴!A:C
```
